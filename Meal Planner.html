Save Your Data

Works in any browser, including iPhone. Export saves (or shares to Google Drive) a copy of your meals and log. Import loads a previously exported file back in. Use the same filename each time — for example, save it over Meal Log.html in this folder — so you're always continuing the same running log.

Auto-Save (Chrome/Edge on a computer)

Optional. When connected, this saves to Meal Log.html automatically after every change — no need to Export. Not available on iPhone; use Import/Export above instead.
